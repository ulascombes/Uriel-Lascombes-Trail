# Site Uriel Lascombes

## Mise en ligne (GitHub Pages)

1. Crée un repo GitHub nommé exactement `uriel_lascombes.github.io`
   (⚠️ underscore possible dans le nom du repo, mais GitHub Pages
   fonctionne mieux avec un repo `<utilisateur>.github.io` — vérifie
   que ton nom d'utilisateur GitHub est bien `uriel_lascombes` ou
   `urial-lascombes`, sinon le site sera servi sur
   `<utilisateur>.github.io/<nom-du-repo>`).
2. Pousse tous ces fichiers à la racine du repo.
3. Dans Settings > Pages, source = branche `main`, dossier `/root`.
4. Le site est en ligne en 1-2 minutes à l'adresse indiquée par GitHub.

## Ajouter un résultat

Ouvre `_data/resultats.yml`, copie un bloc existant en haut, remplis
les champs (laisse vide ce que tu n'as pas). Le site se régénère et
se trie automatiquement — pas besoin de toucher au HTML.

## Ajouter des photos

Dépose tes fichiers dans `assets/images/` (sous-dossiers `courses/`,
`portraits/`, `paysages/` déjà créés). Elles apparaissent
automatiquement sur `/photos/`.
